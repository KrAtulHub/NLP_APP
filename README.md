# 🧠 NLP_APP  
### Natural Language Processing Application using Python, Streamlit & Hugging Face

---

## 📌 Project Description

This is a simple **Natural Language Processing (NLP) web application** built using **Python**, **Streamlit**, and **Hugging Face Transformers**.

The application allows users to analyze text using AI models and perform:

- 🏷️ Named Entity Recognition (NER)
- 😊 Emotion Detection

It provides real-time text analysis through a clean and interactive web interface.

---

## 🚀 Features

- ✍️ Enter any text for analysis  
- 🧠 Detect named entities like people, organizations, locations  
- 😊 Detect emotions in text (happy, sad, anger, fear, etc.)  
- ⚡ Fast Streamlit UI  
- 🤖 Powered by Hugging Face AI models  
- 📊 Instant results in browser  

---

## 🛠️ Tech Stack

- Python 🐍  
- Streamlit 🌐  
- Hugging Face Transformers 🤗  
- NLP (Natural Language Processing)
